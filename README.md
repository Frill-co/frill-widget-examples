# Frill Widget & Survey Examples

Welcome to the Frill Widget & Survey examples repository.

This repository contains advanced usage examples for Widgets & Surveys, including user
identification, SSO, iframes, external control and recommended usage in React & Next.js.

## Using a bundler? Install the package

For React, Next.js, or any app with a bundler, use the
[`@frillco/script`](https://www.npmjs.com/package/@frillco/script) package — a type-safe wrapper
that loads the Frill script for you:

```bash
npm install @frillco/script
```

See the [React](./examples/react) and [Next.js](./examples/next) examples to get started.

## Plain HTML

The `.html` files in [`examples`](./examples) show how to embed Frill with a plain `<script>` tag
(no bundler required) — user identification, SSO, embedding, events, theming and more.

See our [developer docs](https://developers.frill.co/frill-script/) to see what's possible or jump
into [our examples](./examples).
